# Reproducing the paper

Scripts for checking the claims in *Head Position Confounds the DTI-ALPS Index
in Aging and Disease: An Orientation-Aware Refinement* (Magnetic Resonance
Imaging, MAGRESIMAGING-D-26-00371).

Each script says at the top which claims it covers and what it needs. Where a
claim can be checked without any data, the script does that by default, so you
can run it immediately and see the behaviour before deciding whether to download
anything.

## What runs with no data at all

| script | claims covered | runtime |
|---|---|---|
| `../tests/test_invariance.py` | the corrected variants are exactly invariant under rotation while the classic index drifts | seconds |
| `estimator_comparison.py` | why the tract direction is a dyadic average rather than a vector average: sign ambiguity, order dependence, CL against FA as the weight, and why a DEC map hides all of it | seconds |

```bash
python -m pytest tests/test_invariance.py -q
python reproduce/estimator_comparison.py
```

`estimator_comparison.py` sweeps orientation dispersion, because the failure it
demonstrates is conditional. At the dispersion of a real ALPS region the
superseded running vector mean and the dyadic estimate agree closely. Permuting
voxel order moves the running mean by 1.2 degrees at 20 degrees of dispersion
and by more than 80 at 40, while the dyadic estimate does not move at all.

## What runs on public data

| script | claims covered | data |
|---|---|---|
| `head_pose.py` | head pose recovered two independent ways, one of which the brain cannot influence | any NIfTI header, and a FLIRT affine if you have one |

Both cohorts whose results can be redistributed are public:

* Dallas Lifespan Brain Study, OpenNeuro `ds004856`
* the trigeminal neuralgia cohort, OpenNeuro `ds005713`

```bash
# the operator's slab angulation, straight from the image header
python reproduce/head_pose.py --prescription sub-XXXX_dwi.nii.gz

# summarise a whole tree
python reproduce/head_pose.py --prescription-dir /path/to/ds004856 --pattern "**/*dwi.nii.gz"

# and pose from a subject-to-template registration, if you have run one
python reproduce/head_pose.py --affine subject_to_mni.mat
```

The paper measures head pose twice, and the second measurement exists to answer
an objection to the first. The affine method is fitted to brain shape, so
age-related atrophy could in principle shift the recovered rotation without the
head having moved. The slice prescription cannot be affected that way: it is
fixed before the first volume is acquired. In DLBS the prescription tracks age
at r = -0.342 and the affine measure at +0.340, they agree with each other at
r = -0.223, and their difference tracks age at +0.428. The opposite signs are
the interpretable part, since the operator angulated the slab further for older
participants, which is what one does when the head is pitched back.

## What cannot be redistributed

HCP-Aging was accessed under the AABC Consortium Data Use Terms, which prohibit
redistribution. No HCP-Aging identifier, derived value or image appears anywhere
in this repository. Results that depend on it are reported in the paper and can
be regenerated by anyone with their own approved access, using the same code
paths as the public cohorts.

## Computing the index itself

The reproduction scripts above are about the paper's arguments. To compute the
index on your own data, use the package rather than these scripts:

```bash
dti-alps place-rois --fa subject_FA.nii.gz --out rois.nii.gz
dti-alps compute --evals evals.nii.gz --evecs evecs.nii.gz --rois rois.nii.gz
```

See the top-level `README.md`. The regions distributed here are the conventional
5 mm spheres at the published atlas coordinates, so values are comparable with
the literature that uses them.
